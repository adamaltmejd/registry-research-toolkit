# D classification sentinel meanings

Temporary source accounting; deleted with the one-shot conversion reports at milestone F.

The published schema stores the supplied code label and a sentinel bit. It has no
separate sentinel-meaning field. The source label is retained without changing value-set
identity; the differing legacy meanings below are dropped with that reason.

differences, grouped here into 357 exact code/meaning/label combinations. The version
column lists every affected classification. These compare the original 490 declared
code/version pairs; later shared-set normalization adds flags, not invented meanings.
JSON strings preserve exact differences, including null or empty labels.
