mock_data_wizard UI

This is the placeholder served when the Svelte frontend hasn't been built yet. The HTTP API at /api/state is live regardless; this just means there's no SPA on top of it.

To build the frontend (one-time setup needs bun):

cd mock_data_wizard/web
bun install
bun run build

This writes the production bundle into src/mock_data_wizard/static/, replacing this page.
