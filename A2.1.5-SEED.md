## Re-point checklist (when authoring A2.1.5)

The engine targets the per-variant `variable_state.slug` from #133. Re-point to
the register-unique `variable.slug`:

1. **Storage target** — `UPDATE variable_state SET slug ...` → `UPDATE variable
   SET slug ...` (by the promoted `variable_id`).
2. **Uniqueness key** — `seen` keyed `(register_id, register_variant_id, slug)` →
   `(register_id, slug)`; the `slug_variable_collision` message drops the
   "per variant" wording (→ "unique per register", DECISION POINT 1).
3. **Iteration grain** — iterate the promoted `variable` rows, not the
   `(register_id, register_variant_id, var_id)` `variable_state` triples.
4. **`populate_slugs` gate** — lift the `slug_variable_override_unsupported`
   block (kept on this branch so the live path stays green) once
   `populate_variable_slugs` is the wired consumer.
5. **`_variable_source_slug`** — replace the derive-from-aliases body (kept on
   this branch) with a read of the stored `variable.slug`; the
   `slug_same_as_ambiguous_source` branch becomes unreachable (one stored slug).
